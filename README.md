# ⭐ Featured Projects

## ⚖️ DEEBATE — Formal AI Debate Arena

**Multi-agent AI debate simulation platform**

A structured Lincoln-Douglas debate system where multiple AI roles collaborate to conduct and evaluate a formal debate.

### Highlights

- Multi-agent debate orchestration
- Moderator, Affirmative, Negative, Timekeeper, and Judge roles
- Real-time LLM streaming
- Structured debate state machine
- OpenAI-compatible model support
- AI-generated verdict and scorecard
- Web Audio API generated timekeeper sounds
- Custom streaming Markdown renderer
- Modern responsive interface

**Stack:** Next.js · React · TypeScript · Tailwind CSS · LLM APIs · Web Streams · Web Audio API

🔗 [View Repository](https://github.com/sheikh-mohammad-rakib/deebate)

---

## 🔬 Research Copilot

**AI-powered research paper analysis platform**

Research Copilot helps users analyze academic papers by uploading PDFs, generating structured summaries, comparing papers, searching paper content, and asking questions about individual papers.

### Highlights

- PDF upload and text extraction
- AI-generated structured summaries
- Paper-to-paper comparison
- Interactive research-paper Q&A
- Full-text database search
- Persistent paper and comparison history
- PostgreSQL database
- Prisma ORM
- GitHub Models integration

**Stack:** Next.js · TypeScript · Prisma · PostgreSQL · GitHub Models · Vercel AI SDK · Tailwind CSS

🔗 [View Repository](https://github.com/sheikh-mohammad-rakib/research-copilot)

## 🖨️ CUET Print Service

**Hyper-local printing marketplace**

A two-sided printing platform connecting students with printing shops. Students upload documents and configure print jobs while shop owners receive and manage orders in real time.

### Highlights

- Student and shop-owner workflows
- Authentication
- PDF file uploads
- Cloud storage
- Order management
- Real-time order updates
- Shop management
- Print configuration and pricing
- Role-specific dashboards

**Stack:** Next.js · TypeScript · Appwrite · Tailwind CSS · shadcn/ui

🔗 [View Repository](https://github.com/sheikh-mohammad-rakib/cuet-print-service)
